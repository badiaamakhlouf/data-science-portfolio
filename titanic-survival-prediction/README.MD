# Data Science Challenge
Welcome to my Data Science Challenge repository
## Project details 💡
- **Project Scope:** Predicting Titanic Passenger Survival Status
- **Goals:** Develop a machine learning model to predict whether passengers survived the Titanic shipwreck based on demographic and trip-related data.
- **Available Dataset:** use the Titanic dataset containing information like passenger age, gender, class, fare, cabin, and survival status.
- **Accomplished tasks:**
  - Business understanding and Problem Definition 
  - Data Mining : Data understanding, wrangling and EDA 
  - Feature Engineering
  - Model building
  - Model Evaluation and Validation
  - Communication and Reporting
  - Model Deployment

1. Business understanding and Problem Definition:  aims to identify the objectives, business requirements and to clearly define the specific problem that needs to be solved to ensure that the data science project aligns with the overall business goals.
2. Data Mining : Data understanding, wrangling and EDA : explore dataset structure, statistical description, distributions, missing values, ouliers, class imbalance etc. Handle missing data through imputation technique or exclusion. Visualize relationships between features and survival etc.
3. Feature Engineering: filter the relevant features in the classification process, encode categorical variables using One-hot encoding and scale numerical features using Z-score normalization.
4. Model building: I evaluated various classifiers suitable for binary classification, including decision trees, random forests, logistic regression, SVM, and KNN. Model training was conducted using grid search and cross-validation techniques to tune hyperparameters and optimize performance.
5. Evaluation and Validation: calculate various evaluation metrics like accuracy, precision, recall, f1-score. Then plot the  ROC-AUC curve.
6. Communication and Reporting: assess all the previous evaluation metrics to select the best model to be deployed in the next step. Communicate findings and insights effectively, potentially visualizing key relationships and predictions.
7. Deploy the final model for predictions.

This summary outlines the essential steps to build, train, and evaluate a predictive model for determining Titanic passenger survival. ✅
